# Variable
## Vòng đời
Javascript quản lý biến theo 3 bước được gọi là vòng đời của 1 biến (Variable lifecycle):
1. **Declaration:** Registers the variable name within its scope (creates a binding).
2. **Initialization:** Allocates memory and automatically sets an initial value (defaults to `undefined`).
3. **Assignment:** Assigns an explicit value to the variable defined by your code.![[2.jpg]]
