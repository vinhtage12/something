# Tech Digest 27/11/2026

> Lưu ý: Hacker News, cisa.gov, Wikipedia và Smithsonian không truy cập được từ môi trường này nên không có mục KEV/HN; fun fact dựa trên kết quả tìm kiếm (chưa mở được trang gốc).

- **Docker Engine 29.10.1: vá lỗi đọc không giới hạn và race `docker cp`** (tag: Security) - Sửa việc đọc không giới hạn khi parse file user/group/ID mapping, và race cho phép process trong container biến bind mount read-only thành writable khi `docker cp`. Cập nhật host và CI runner; bản này kèm BuildKit v0.35.1, [source](https://github.com/moby/moby/releases)
- **Node.js 26.13.1 LTS security release: nhiều lỗi High ở HTTP/2 và TLS** (tag: Security) - Sửa lỗi HTTP/2 (stream/header), mTLS session resumption, SNI và một lỗi crash server từ xa. Nếu tự host Next.js/NestJS thì nên nâng Node trong Dockerfile, [source](https://github.com/nodejs/node/releases)
- **Next.js 16.5.0-canary.68 vá lỗi bypass authorization ở Go proxy RSC** (tag: Security) - Canary này sửa lỗi RSC dot-segment authorization bypass trong Go proxy helper (mới là canary, theo dõi khi lên stable). Canary.67 bật mặc định `durableUseCacheEntries`, [source](https://github.com/vercel/next.js/releases)
- **NestJS 12.6.3** (tag: BE) - Phát hiện route conflict giống router (Express coi `GET /users` và `GET /Users` là một, `duplicate: 'error'` sẽ chặn bootstrap), `@Body('key')` với body falsy trả `undefined`. 404 không còn tạo stack trace, giảm khoảng 28% CPU mỗi lần 404, [source](https://github.com/nestjs/nest/releases)
- **NestJS 12.6.1/12.6.2: Fastify cần Node 20.19+/22.12+** (tag: BE) - `@fastify/middie` 9.3.x yêu cầu Node mới hơn. `res.send()` giờ pipe `Readable` stream thay vì serialize JSON; RabbitMQ có `nackOnInternalError`, [source](https://github.com/nestjs/nest/releases)
- **Prisma 8.0.0-rc.25** (tag: BE) - Thêm nested transactions `tx.transaction(callback)`, client MariaDB; CLI từ chối migration phá vỡ ràng buộc dữ liệu. Breaking: `pg` thành peer dependency, `PrismaNextConfig` đổi thành `PrismaConfig`; bản stable vẫn là 7.10.1, [source](https://github.com/prisma/prisma/releases)
- **Spring Boot 4.2.0 (cùng 4.1.3, 4.0.10)** (tag: BE) - Dùng Spring Framework 7.1.0, Spring Security 7.2.0, Hibernate 7.4.15; deprecate Apache Pulsar. Các bản patch sửa lỗi zip class-loading và URL PostgreSQL trong Docker Compose, [source](https://github.com/spring-projects/spring-boot/releases)
- **GitHub Trending: skill/plugin cho AI coding agent tiếp tục dẫn đầu** (tag: AI) - `elementalsouls/Claude-BugHunter`, `obra/superpowers`, `HKUDS/CLI-Anything`, `cathrynlavery/diagram-design` đều trong top. Xu hướng đóng gói quy trình thành skill cho agent, [source](https://github.com/trending)
