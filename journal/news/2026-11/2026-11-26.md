- **CISA KEV (18/11): thêm Synology DSM, BerriAI LiteLLM, Apache Axis, REDCap** (tag: Security) - Kết quả tìm kiếm cho biết 4 lỗ hổng đang bị khai thác; hạn vá của cơ quan liên bang là 21/11 (DSM, REDCap, Axis) và 02/12 (LiteLLM). Nếu bạn dùng LiteLLM proxy trong stack AI/dev thì nên kiểm tra và nâng cấp ngay (chưa xác minh CVE ID, hãy đối chiếu catalog chính thức), [source](https://letsdatascience.com/news/cisa-adds-four-exploited-flaws-including-litellm-to-kev-cata-4eb52bab)
- **Docker Engine 29.10.1 vá 2 CVE** (tag: Security) - Sửa CVE-2026-135844 (đọc không giới hạn khi parse file user/group) và CVE-2026-135124 (`docker cp` biến bind mount read-only thành writable). Cập nhật host và CI runner; bản này kèm BuildKit v0.35.1, [source](https://github.com/moby/moby/releases)
- **NestJS 12.6.1 / 12.6.2 ra trong ngày 25/11** (tag: BE) - Thêm RabbitMQ `nackOnInternalError`, `ParseDatePipe` chặt hơn, Express từ chối multipart field name kiểu prototype key (400). `res.send()` giờ pipe `Readable` stream thay vì serialize JSON; 12.6.2 khôi phục type-check cho `applyDecorators()`, [source](https://github.com/nestjs/nest/releases)
- **NestJS Fastify adapter yêu cầu Node 20.19+ / 22.12+** (tag: BE) - Cả 12.6.1 và 11.2.12 nâng `@fastify/middie`; Node cũ hơn sẽ lỗi `ERR_REQUIRE_ESM`. Middleware app-level giờ chỉ chạy một lần mỗi request, nên kiểm tra Node version trong Dockerfile/CI trước khi nâng cấp, [source](https://github.com/nestjs/nest/releases)
- **Spring Boot 4.2.0 (cùng 4.1.3, 4.0.10)** (tag: BE) - 4.2.0 dùng Spring Framework 7.1.0 và Spring Security 7.2.0, deprecate Apache Pulsar. Các bản patch sửa lỗi zip class-loading, URL PostgreSQL trong Docker Compose, RabbitMQ và SAML2 metadata, [source](https://github.com/spring-projects/spring-boot/releases)
- **Next.js 16.5.0-canary.62: CSS order và Turbopack cache** (tag: FE) - Canary mới sửa thứ tự CSS webpack runtime trước lần commit đầu của App Router; canary.61 giúp Turbopack tự phục hồi khi persistent cache hỏng và thêm hỗ trợ thử nghiệm `@next/safe-image-optimization`. Mới là canary, nhưng đáng theo dõi, [source](https://github.com/vercel/next.js/releases)
